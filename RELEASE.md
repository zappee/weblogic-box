# Release Notes — zappee.github.io

All notable changes to this project are documented in this file.

## [2.2.0] - 02/Oct/2026

#### Changed
* Updated documentation and guides.
* Cleaned up the repository by removing redundant assets, legacy files, and unused code blocks.
* Changed project licensing.

## [2.1.0] - 13/Dec/2022

#### Changed
* Refactored and optimized bash scripts.
* Integrated an SSH server into the images to enable native `ssh` and `scp` capabilities between running containers.
* Migrated the `template.jar` download mechanism from `netcat` to secure `ssh`.
* Streamlined the process for opening new WebLogic Scripting Tool (`WLST`) sessions from managed servers to the administration server.
* Updated documentation and guides.
* Optimized Splunk index size configuration limits.

## [2.0.0] - 19/May/2022
* Initial stable release, ready for use.
